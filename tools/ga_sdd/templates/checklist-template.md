# SDD Checklist — [Project/Feature]

## Spec Quality
- [ ] Goals and non-goals are explicit
- [ ] User stories have independent acceptance criteria
- [ ] Success criteria are measurable
- [ ] No unresolved NEEDS CLARIFICATION markers unless intentionally blocked

## Plan Quality
- [ ] Plan references the current spec
- [ ] Gates and verification are defined
- [ ] Risks and tradeoffs are recorded

## Task Quality
- [ ] Tasks are numbered
- [ ] Tasks include file paths when possible
- [ ] User-story tasks are independently testable
- [ ] Parallel tasks are marked [P]

## Sync Quality
- [ ] AGENTS.md map is still current
- [ ] contracts/ and validation docs are checked if interfaces changed
